树莓派网络麦克风 · Windows 端
================================

这个文件夹里是电脑侧的程序，接收树莓派降噪后的麦克风音频并播放，同时把电脑的
声音（系统回环或麦克风）发回树莓派耳机口。

一、安装（只做一次）
--------------------
1) 装 Python 3.8 以上（https://www.python.org/downloads/ ，安装时勾选
   "Add python.exe to PATH"）。
2) 双击 **启动.bat**：它会自动执行 pip install soundcard numpy 然后打开界面。
   也可以手动：
       pip install -r requirements.txt
       python btmic_net_gui.py
   国内网络慢时加镜像：
       pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

二、使用
--------
1) 界面上选连接方式：
     * TCP 直连 —— 树莓派和电脑在同一 WiFi/热点时用；电脑要有公网 IP 或做了
       内网穿透时，跨互联网也能用（音质最好：48kHz 立体声）。
     * MQTT 中继 —— 只要双方都能上网就行，不需要公网 IP（中继模式的音质和
       稳定性受免费 broker 限制）。
2) 点 **启动服务**。第一次会弹 Windows 防火墙提示，选"允许访问"。
3) 点 **把连接参数复制给树莓派**，把复制到的命令粘到树莓派 SSH 里执行。
4) 底部 **音频自检** 可以在没连树莓派时先确认"电脑这边有没有声音"。

三、界面上各块是干什么的
------------------------
① 连接设置：端口/broker/令牌（令牌两端必须一致，点"换一个"随机生成）
② 上行：树莓派麦克风 → 电脑。选播放设备、调音量、勾"同时录音到 WAV"
③ 下行：电脑声音 → 树莓派耳机口。选采集来源（"系统声音·xxx（回环）"=
   电脑正在放的所有声音；"麦克风·xxx"=你说的话）、调音量、
   "远端麦克风增益"相当于给树莓派的麦克风调音量（0~15）
④ 状态：连接状态、收发帧数、抖动缓冲、往返延迟
⑤ 日志：出问题先看这里

四、注意事项
------------
* 树莓派与电脑在同一个房间演示时，电脑建议戴耳机，否则会形成"树莓派喇叭 →
  树莓派麦克风 → 电脑 → 树莓派喇叭"的回声回路，可能啸叫。
* 下行格式（采样率/声道/帧长）以树莓派侧的 NET_DOWNLINK_* 配置为准，
  界面上的"下行格式"只是兜底。
* 完整说明（含 4G 模块安装、接线、固件、排查手册）见上一级目录的
  《4G模块安装与网络音频使用说明.md》。
* 改了界面上的设备/音量会存在 btmic_net_gui.json 里，下次自动带上。

五、自检（可选）
----------------
上一级的 tests/ 里有三个脚本，在本机跑一遍能验证协议与音频通路：
    python tests/test_proto.py      # 帧解析 + MQTT 报文解析 + 真 broker 收发
    python tests/test_e2e.py tcp    # 真声卡端到端（电脑↔"树莓派"双向音频）
    python tests/test_e2e.py mqtt   # 同上，走公共 broker

六、打包成单一 exe（免装 Python、没有控制台窗口）
------------------------------------------------
本目录里的 **树莓派网络麦克风.exe** 就是打包好的单文件程序（约 25MB）：
* 双击即用，**不需要装 Python**，也不会弹控制台窗口；「启动.bat」会优先用它。
* 配置与录音文件都保存在 **exe 旁边**（btmic_net_gui.json / *.wav）。
* 首次启动要解压自己，等 3~5 秒属正常。
* 没有数字签名，个别机器的 SmartScreen 会提示"未知发布者"——点"更多信息 → 仍要运行"。
* 想自己重新打包（改过源码后）：
      pip install pyinstaller
      pyinstaller --onefile --noconsole --name 树莓派网络麦克风 btmic_net_gui.py
* 出问题先跑自检（命令行里）：
      树莓派网络麦克风.exe --selftest
  它会把结果写到同目录的 btmic_selftest.txt（程序目录/配置路径/音频设备/闭环检查）。

七、采集来源怎么选（很重要，选错就"听不清"）
------------------------------------------------
* 「麦克风」= 你说的话 → **双向对讲必须选这个**（电脑说话，树莓派听见人声）。
* 「系统声音 · xx（回环）」= 电脑正在放的声音（音乐/视频），**不包括**你的说话。
* 若选「系统声音」而本程序又在同一路扬声器上播放树莓派的声音，就形成闭环：
  树莓派会听见自己的回声（听起来是"有响声但听不清内容"）。程序检测到这种组合会
  在界面上红字告警，并给出「改用麦克风」一键切换。
